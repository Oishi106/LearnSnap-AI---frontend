# 🚀 Overview

LearnSnap AI is an AI-powered **vision-to-text** web application developed for the **Build with Gemma @ Bangladesh Hybrid Hackathon 2026**.

Instead of chatting with AI, users simply upload an image and receive structured, intelligent results generated by **Gemma 4 Vision**.

The platform is designed to solve two real-world problems common in Bangladesh.

---

# 📖 Whiteboard Study Guide

Take a photo of any classroom whiteboard.

LearnSnap AI automatically transforms it into:

- 📑 Structured Markdown Notes
- 🧠 Topic-wise Explanation
- 📚 AI Summary
- 💡 Key Concepts
- 🎴 Interactive Flashcards
- ❓ Practice Quiz

Perfect for quick revision before exams.

---

# 💊 Prescription Explainer

Upload a doctor's prescription.

Gemma helps users understand:

- Medicine Names
- When to Take Them
- Medical Short Forms
- General Purpose of Medicines

⚠️ The application never provides medical advice or changes prescriptions.
